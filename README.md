Re-Implementation of the front end for Google’s homepage, which meets the following specifications:
1. It contains three pages: one for regular Google Search,one for Google Image Search,
   and one for Google Advanced Search
2. Text Search: users can type in a query, click “Google Search”, and they are taken to
   the Google search results for that page
3. "I'm Feeling Lucky"-Button: Consistent with Google’s own behavior, clicking this link takes
   users directly to the first Google search result for the query, bypassing the normal results page
4. Image Search: users can type in a query, click a search button, and are taken to the
   Google Image search results for that page
5. Advanced Search: users can provide input for the following four fields 
  - Find pages with… “all these words:”
  - Find pages with… “this exact word or phrase:”
  - Find pages with… “any of these words:”
  - Find pages with… “none of these words:”
